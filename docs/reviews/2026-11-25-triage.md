## 3. The reviews differ: recommendation

| Topic | R1 | R2 | Recommendation |
|---|---|---|---|
| Address check and cost check before payment | Keep the estimation task and run the cost guard **before** payment (F9) | Drop the estimation task from the quote; check ZIP ↔ state locally (F6) | **R2 for the quote** (the capture showed estimation only catches state/ZIP errors, which a local table catches in < 1 ms; the quote stays one Printful call, Q6 holds) **plus R1's intent**: a pre-payment cost check from cached catalog prices + the quoted shipping. The exact post-payment guard stays as the backstop. |
| Cost guard tolerance | None; a positive `MARGIN_FLOOR_CENTS` (F9) | `COST_GUARD_TOLERANCE_CENTS` = $1 (F9) | **One knob**, `MARGIN_FLOOR_CENTS`, default 0: retail is dollars above wholesale, so cent-level drift never matters; a misconfiguration does. |
| Shop images | The shop renders and serves its own display images; CSP stays `'self'` (F21.6) | Allow the source origin in `img-src` (F4) | **R1**: no dependency on art's URL scheme or uptime, no metadata in served images, Lighthouse unaffected. |
| Re-render on art's `v` change | — | Gate on the original's SHA-256, not `v` (F4) | **R2**, adopted. |
| Late payment edge | `abandoned/expired → paid`, processed normally (F1, with F5's split states) | `→ needs_attention`, Klaus alerted (F5) | **R1**: with payment and fulfilment as separate fields (R1 F5), a late payment is just a payment; no work for Klaus (R9). |
| Admin login in e2e tests | A login route only in mock mode, refused with real keys (F27) | No test route; Playwright mints a real signed cookie with a test secret (F8) | **R2**: no backdoor code at all. |
| Redaction of captures | Allow-list per endpoint, ids rewritten, CI fixtures check (F26) | More regexes + a CI test (F8) | **R1's allow-list** plus R2's CI test; and with ADR-0028 the raw captures live in the private repository, the public repo only gets synthetic fixtures. |
